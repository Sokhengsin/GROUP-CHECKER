Roblox Community Checker

Eligibility Checker

Check whether a Roblox account is currently a member of a public Roblox community, and estimate the configured membership-age requirement when a trustworthy join date is available.

How it works

Membership check

Paste any public Roblox community link (roblox.com/communities/… or roblox.com/groups/…). The server resolves the username, reads the account's public community memberships from Roblox, and confirms whether it belongs to that community, along with its current role and rank.

Roblox's public endpoints do not show when a member joined. If the site owner has set up an optional Roblox Open Cloud key that can read this community, the server also fetches the join time and estimates when the configured membership-age requirement is met. Otherwise no join date is shown. It is never guessed.

This checker only verifies membership information and estimates the configured membership-age requirement when Roblox provides a trustworthy join timestamp. Roblox may apply additional payout restrictions.
